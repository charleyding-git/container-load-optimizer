# 集装箱与托盘规格表

## 数据来源

- **集装箱内尺寸 / 门开口高**：ISO 668 + Hapag-Lloyd / GoFreight / Nexportal 公开规格表交叉核对
  （ISO 668 只规定外部尺寸；内空与门开口各箱厂略有差异，此处取主流值）
- **托盘尺寸**：ISO / GB / GMA 标准
- **行业约束**：见 `modeling_basis.md`

**⚠️ 差 1 个托盘位 = 差 1 个柜。** 托盘位数量是货量的硬天花板。

## 三段式 Y 交错布局说明

美标托盘塞满 21 个的结构（40HQ）：

```
段① 下排: 11 个 B 朝向 (1016 宽 × 1219.2 深)  y ∈ [0, 1219.2)
段② 上排: 10 个 A 朝向 (1219.2 宽 × 1016 深)  y ∈ [1016, 2235.2)
         两者 X 区间部分重叠，靠 Y 错位避开 → 合计 21
柜宽 2352，实用到 2235.2，剩余 116.8mm 余量
```

在 `engine.pallet_floor_layout` 中以参数化枚举实现，纯结构解、零随机、可复现。
